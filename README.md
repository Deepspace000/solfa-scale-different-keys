# Solfa Scale Different Keys

Pick any key and any of 159 scales and modes, read the scale on a staff in solfa, note names and numbers with a handsign over each note, then press Improvise for a melody over chords taken from the same scale.

Live page: https://deepspace000.github.io/solfa-scale-different-keys/

- 12 keys with sharp, flat or automatic spelling
- Major and its modes, harmonic and melodic minor families, pentatonic, blues, Japanese, ragas, all 72 Carnatic melakartas, symmetric and Messiaen scales, bebop, and Kodaly tritonic to hexatonic
- Extended lower and upper range, four clefs, key signature, colour by degree, keyboard strip
- Chord cards, and an improviser with swing, drums, several instruments and MIDI download

The whole app is the single file `index.html` and works offline. The notation uses VexFlow 4.2.2 (MIT licence), which is built into the file.
